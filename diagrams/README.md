# Diagrams

**Status: Planned**

Conceptual architecture diagrams for the KagePoint Systems design.

## What will appear here

Zone-model and trust-boundary diagrams, control-plane separation, and phase-flow diagrams -
all at the conceptual level.

## What will not appear here

Addresses, subnets, zone identifiers, hostnames, device identifiers, rack layouts, or anything
that would function as a map of the actual environment.

A diagram is only publishable here if it would still be safe to publish if it were completely
accurate.

## Current contents

None yet. The zone model is currently expressed as a text diagram in the
[README](../README.md) and in
[KAGEPOINT_SYSTEMS_ARCHITECTURE.md](../docs/01_Architecture/KAGEPOINT_SYSTEMS_ARCHITECTURE.md).
