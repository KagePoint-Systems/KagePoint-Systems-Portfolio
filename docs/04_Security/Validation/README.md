# Validation

**Status: Documented** - not claimed as implemented, tested, or validated.

Last updated: 2026-08-07

---

## Scope

The evidence model that determines when something counts as working.

## Design principles applied

- Five maturity levels: Planned, Documented, Implemented, Tested, Validated
- Promotion above Planned requires a real artifact in a stated location
- **Validated additionally requires a validator independent of whoever did the work**
- Evidence records date, method, operator, and result, including failures
- Evidence must be reproducible on request
- Fabricated evidence is a hard block on any promotion

## Public-detail note

Evidence artifacts are held internally and are not published.
