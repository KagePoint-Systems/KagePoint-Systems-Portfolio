# Access Control

**Status: Documented** - not claimed as implemented, tested, or validated.

Last updated: 2026-08-07

---

## Scope

Named accounts, least privilege, MFA coverage, and periodic access review.

## Design principles applied

- Named administrative accounts; no shared credentials
- MFA enforced on administrative interfaces
- Access is scoped per task rather than per person where possible
- Entitlements are reviewed on a schedule, with the review recorded
- Emergency credentials and access-control ownership are human-controlled

## Public-detail note

Account inventories and entitlement detail are not published.
